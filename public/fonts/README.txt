Copia aca el archivo de la fuente de marca descargado de dafont:

  YNTKTS.ttf

Se usa a traves de la variable CSS --font-brand (src/styles.scss). Por ahora solo la usa el titulo del Home.
Para usarla en otro lado (ej. navbar):  font-family: var(--font-brand);

IMPORTANTE: muchas fuentes de dafont son "gratis solo para uso personal". Como esta web es comercial,
revisa la licencia que viene con la fuente (o pedile permiso al autor) antes de publicar.
